# SEO en GEO — Rossenaar Marketing

Datum: 11 oktober 2026. Domein: https://www.rossenaarmarketing.nl.

## Beoordeling en gekozen richting

De website heeft een bruikbare technische basis: Next.js levert HTML op de server, de belangrijkste pagina’s zijn bereikbaar en het echte klantwerk ondersteunt Danny’s persoonlijke verhaal. De grootste kansen lagen in duidelijkere dienstenpagina’s, samenhangende bedrijfsinformatie en een meetbare start via Search Console. In deze wijziging zijn de websiteonderdelen aangepakt; eigendomsverificatie bij zoekmachines staat nog open. Enkhuizen en West-Friesland vormen de primaire focus, met landelijke beschikbaarheid en inhoudelijke dienstenpagina’s voor ondernemers elders in Nederland.

Dit is een implementatie plus kwalitatieve audit, geen gemeten rankingrapport. Er is geen gekoppelde Ahrefs/Semrush- of Search Console-dataset. Zoekvolumes, huidige posities, backlinks en autoriteitsscores zijn daarom onbekend. Voor precieze volume- en moeilijkheidsgegevens is een SEO-databron nodig. De openbare zoekresultaten en concurrentpagina’s geven richting, geen bewijs van een vaste positie of zoekvolume.

## Techniek en GEO

| Controle                      | Status                    | Details                                                                                                                        |
| ----------------------------- | ------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| HTTPS / www                   | Pass                      | Publieke hoofdroute en beide nieuwe klantcases geven 200 op www; canonicals gebruiken één domein                               |
| HTML zonder client-JavaScript | Pass                      | Inhoud, vragen, links, metadata en JSON-LD staan in de serverrespons                                                           |
| Robots                        | Pass                      | Openbare inhoud toegestaan via `*`; `/api/` uitgesloten                                                                        |
| AI-zoekcrawlers               | Pass op siteniveau        | Geen eigen blokkade voor OAI-SearchBot; valt onder `*`. CDN/firewall-toegang nog controleren bij productie                     |
| Sitemap                       | Pass                      | 15 indexeerbare document-URLs; ook beelden en zes lokale videoverwijzingen bij hun cases                                       |
| Preview-indexering            | Ingericht                 | `VERCEL_ENV=preview` krijgt noindex, robots-disallow en een lege sitemap                                                       |
| Structured data               | Pass in lokale controles  | Organization, Person, WebSite, WebPage/ContactPage/AboutPage, BreadcrumbList, Service en CreativeWork met vaste gekoppelde IDs |
| Lokale bedrijfsmarkup         | Bewuste beperking         | Organization gebruikt het bevestigde werkgebied. Geen verzonnen straatadres, KvK, openingstijden of LocalBusiness-rating       |
| Reviews                       | Pass                      | Bestaande citaten blijven; geen zelfgemaakte AggregateRating of resultaatclaims                                                |
| Interne links                 | Automatisch gecontroleerd | Alle documentlinks en ankers uit de gerenderde pagina’s worden gecontroleerd                                                   |
| Foutpagina’s                  | Automatisch gecontroleerd | Niet-bestaande dienst en case moeten 404 + noindex geven                                                                       |
| Mobiel en thema               | Pass in visuele controles | Nieuwe pagina’s op 390 × 844, licht/donker; vragen openen en tekst loopt binnen het scherm                                     |
| Beeld en video                | Pass in broninspectie     | Next Image, formaten gereserveerd, lokale media, casevideo’s preload=none; geen Instagram-iframe                               |
| Core Web Vitals               | Warning                   | Geen CrUX/Search Console-metingen. PageSpeed API gaf HTTP 429 (dagquota). Er is dus geen geverifieerde LCP/INP/CLS-score       |
| Google Search Console         | Open                      | Gebruiker bevestigt: alleen Google Bedrijfsprofiel is ingericht. De browser heeft geen aangemelde Search Console-sessie        |
| Bing Webmaster Tools          | Open                      | Account/verificatie niet beschikbaar; optionele verificatietag voorbereid                                                      |
| Indexatie en AI-vermeldingen  | Onbekend                  | Crawlen/indexeren en daadwerkelijke vermeldingen moeten na publicatie gemeten worden                                           |

GEO bestaat hier uit begrijpelijke, aantoonbare informatie: wie Danny is, wat de diensten inhouden, waar hij werkt, hoe de samenwerking gaat en welk klantwerk daarbij hoort. Het bedrijfs- en persoonsprofiel verwijzen naar elkaar en naar dezelfde contactgegevens. Antwoorden op praktische vragen staan in HTML, gekoppeld aan zichtbare inhoud en echte cases.

Google noemt geen extra technisch AI-schema of verplicht AI-tekstbestand; bestaande SEO-principes blijven van toepassing. Toegankelijkheid, nuttige tekst en overeenstemming tussen zichtbare inhoud en schema zijn daarom de basis. Dit garandeert geen vermelding in AI-antwoorden. Zie [Google: AI features and your website](https://developers.google.com/search/docs/appearance/ai-features).

OAI-SearchBot is bedoeld voor ChatGPT Search; GPTBot heeft een ander doel. De bestaande trainingstoegang is niet aangepast. Zie [OpenAI crawlerdocumentatie](https://developers.openai.com/api/docs/bots). JSON-LD wordt veilig geserialiseerd volgens de [Next.js-documentatie](https://nextjs.org/docs/app/guides/json-ld). De organisatie bevat alleen bekende bedrijfsgegevens, aansluitend op [Google’s Organization-richtlijn](https://developers.google.com/search/docs/appearance/structured-data/organization).

Er is geen trackingcode toegevoegd; de bestaande privacyverklaring blijft daardoor inhoudelijk passend.
